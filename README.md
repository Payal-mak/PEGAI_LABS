# PEGAI Labs

This repository contains practical experiments, lab assignments, and projects developed as part of the **Prompt Engineering and Generative AI (PEGAI)** course.

## Repository Structure

### LAB1 — Snake Game

A Python-based Snake Game developed as the first practical experiment.

**File:**

- `LAB1/snake_game.py`

### Lab2 — PEGAI Experiment 2

A Jupyter Notebook containing the second PEGAI practical experiment.

**File:**

- `Lab2/PEGAI_exp2_payal.ipynb`

### AI Persona — AI Career Counsellor

An AI-powered career counselling web application that provides guidance using multiple specialized AI personas.

The application includes different counsellor perspectives such as:

- Technical Career Counsellor
- HR & Placement Counsellor
- Academic & Research Counsellor
- Entrepreneurship Counsellor

Users can select one or multiple personas and receive career advice based on their chosen perspectives.

**Technologies Used:**

- HTML
- CSS
- JavaScript
- Gemini API
- Prompt Engineering

**Files:**

- `AI Persona/index.html`
- `AI Persona/ps.txt`
- `AI Persona/README.md`

## Purpose

The purpose of this repository is to maintain all PEGAI laboratory work and practical implementations in one organized repository, with each experiment or project stored in its own folder.
